NotifySound

Sonidos para las notificaciones que se quedan en silencio.

100% Gratis y de Código Abierto Licencia MIT Linux / GNOME Python + GTK4
Ver en GitHub Instalarlo ahora

01El problema

En GNOME, una notificación solo hace sonido cuando la app que la envía incluye explícitamente un hint sound-name o sound-file. La mayoría de apps nunca lo hacen — Warp, terminales, compilaciones de IDE, herramientas tipo cron — así que sus notificaciones quedan completamente mudas.

Las apps que sí reproducen su propio sonido (Telegram, PWAs de WhatsApp, etc.) no se tocan por defecto. Desactiva "no repetir" si quieres ambos sonidos intencionadamente.

02Características

Sonido para cualquier notificación silenciosa

El daemon observa las rutas de notificaciones de GNOME, GTK y freedesktop, y reproduce tu sonido cuando una app envía una notificación sin uno.

Sin sonidos duplicados

Se respetan las notificaciones con sonido propio (o que declaran suppress-sound).

Control por aplicación

Activa/desactiva cada app y dale su propio sonido. Las apps se detectan automáticamente y se agrupan por proceso (así AIMP aparece como una sola entrada, no una por canción).

Alias y fusión de apps

Renombra las apps detectadas a un nombre amigable ("AIMP" en vez de un id de proceso). Fusiona duplicados renombrándolos al mismo alias; deshazlo desde el popover de información.

Archivos de sonido propios

Añade tus propios OGG/WAV/FLAC (y MP3/M4A/AAC con GStreamer, ffplay, mpv o mpg123).

App de ajustes GTK4 sencilla

Elige sonidos, pruébalos, gestiona apps y el estado del daemon desde una ventana.

Instalación por usuario

El instalador desde fuente no necesita sudo; en Ubuntu/Debian también puedes usar el paquete de la release.

03Instalación

Paquete para Ubuntu / Debian (recomendado):

Descargar .deb Checksum SHA-256 
sudo dpkg -i ./notify-sound_0.1.10_all.deb
sudo apt-get -f install

O instala por usuario desde fuente (sin sudo):

Dependencias de Ubuntu / Debian:

sudo apt install python3-gi gir1.2-gtk-4.0 gnome-session-canberra dbus

Luego clona e instala (sin necesidad de sudo):

git clone https://github.com/ChristianM023/notify-sound.git
cd notify-sound
./install.sh

Uso:

notify-sound            # abre la GUI de ajustes
notify-sound --daemon   # inicia el daemon
notify-sound --quit     # detiene el daemon

Otras distribuciones: consulta el README para requisitos y alternativas.
